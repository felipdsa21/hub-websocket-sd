# Hub Colaborativo WebSocket

Aplicação de mensagens em tempo real usando WebSockets no API Gateway da AWS. Funciona como um mini-Teams só de chat: conversas privadas e em grupo, com presença online e histórico. As funcionalidades e os requisitos estão na [especificação](docs/especificacao.md), e a arquitetura e o esquema de nomeação, em [docs/arquitetura.md](docs/arquitetura.md). O design da interface está no [Figma](https://www.figma.com/design/ThG8NUReHI5c9tYzXdaU6z/Hub-Colaborativo-WebSocket).

Projeto da disciplina de Sistemas Distribuídos (Tema 4). O detalhamento do tema está em [docs/tema-4-api-gateway-websockets-detalhamento.pdf](docs/tema-4-api-gateway-websockets-detalhamento.pdf).
